# 微信接入与会话管理

SEUdaily 直接实现[腾讯官方 openclaw-weixin iLink HTTP 协议](https://github.com/Tencent/openclaw-weixin/blob/main/docs/protocol_zh_CN.md)，无需安装 OpenClaw，也无需申请企业微信 webhook。账号是否具备接入资格、手机上的确认和验证码，以微信实际提示为准。当前支持个人账号的文字聊天、文件上传和会话管理，文字消息接入现有 Agent；模型配置与 Web/TUI 共用。真实微信账号接入需要本人实测。

## 首次接入

```sh
seudaily wechat
# 使用指定服务时，带上相同的数据目录和端口：
seudaily wechat --data-dir /path/to/data --port 4111
```

命令优先连接同版本、同数据目录、同端口的已有后端。没有后端时启动独立常驻后端；已有临时后端则转为常驻，保留当前任务和连接。终端会展示实际二维码，用微信扫一扫，在手机确认绑定。终端需要足够的行列数容纳二维码和白色留边；不足时界面会提示具体尺寸，扩大窗口或改用网页。

如果微信要求验证码，输入手机上显示的验证码后按 Enter。二维码过期或验证次数过多时按 R 重新扫码（验证码输入期间用 Ctrl+R 刷新）。连接后 R 只刷新状态，Ctrl+R 可重新扫码。Esc / Ctrl+C 只退出接入界面，微信收发和后端继续运行。

也可以执行 `seudaily web`，点击左侧底部“微信”。二维码会以浮层展示；从终端开始扫码后，网页也会自动弹出同一个接入请求。手机验证码可以在任一界面输入。关闭浮层不取消接入；“取消接入”停止此次扫码并恢复原先有效的绑定，不删除旧凭证。

非交互终端（输出重定向或管道）中的 `wechat` 只确保后端常驻并打印状态，不自动发起扫码；随后在交互终端或网页完成接入。

## 聊天与会话

绑定后，发送 `/help` 查看命令。这些命令不需要模型 API key。首次发送普通文字时自动创建会话，之后默认继续这个会话；普通聊天需要在 SEUdaily 网页或终端的设置中配置模型。

| 命令 | 用法 |
| --- | --- |
| `/help` | 查看全部命令 |
| `/new [名称]` | 新建并切换到会话；旧记录保留，例如 `/new 电磁学复习` |
| `/sessions [页码]` | 每页列出 10 个会话；★ 为当前会话；编号固定，不随排序变化 |
| `/use 编号` | 切换会话，例如 `/use 2`；回复会话名称和最近一条讨论 |
| `/delete [编号]` | 删除指定会话；省略编号为当前会话。先预览，再在 5 分钟内发送 `/delete 编号 确认`；`/delete 编号 取消` 放弃删除 |
| `/context` | 查看当前会话的压缩摘要（如果已有）、最近讨论及图片附件名称 |
| `/history [页码]` | 按当前分支查看最近对话，每页 6 条消息；1 为最新，2 为更早记录 |

会话不会按日期或空闲时间自动切换。长会话沿用 Agent 的摘要压缩，完整历史保留；没有压缩摘要时 `/context` 直接显示最近讨论，不调用模型临时生成摘要。为避免微信刷屏，历史中的长消息和长回复会缩略，完整记录在网页或终端查看。默认的新会话收到第一条普通文字后自动使用其内容命名；`/new 名称` 的自定义标题保留。网页左侧会话列表在标题下显示“创建于微信”（其他入口显示网页、终端或程序，旧记录来源未知时显示本地）。升级时已有“微信 · 新对话”按第一条历史消息补上标题。需要时刷新列表；查看或切换网页/终端会话不会改变微信的当前会话。删除微信的当前会话后，下一条普通文字自动创建新的会话；旧编号不复用。删除会话会同步移除 Web/TUI 中的本地历史、运行状态、摘要和排队任务；已发送的微信入站记录擦除文本与回复，保留去重 ID，避免重连把旧消息重新执行。微信手机上的聊天记录和共享附件文件不会被删除。正在运行、等待审批或还有微信待发送回复的会话需先处理完成，不能直接删除。

同一会话的消息按接收顺序交给 Agent。回答生成期间仍可使用 `/help`、新建或切换会话；每条消息在入站路由时固定内部会话，切换不会把旧任务的回答放进新会话。旧任务完成时，若当前会话已经变化，微信回复会标明它来自哪个会话。普通权限下，工具审批会直接在微信显示变更内容和编号，回复“确认 编号”或“取消 编号”即可处理，也可使用 `/approve 编号` 或 `/deny 编号`。微信不会自动批准；校园登录和验证码仍需网页/终端处理。已启用完全访问模式时，用户明确要求的本地课表变更可按现有权限执行。

接收兼容可选 type/state 字段缺省及 NEW/FINISH 用户消息，过滤生成中消息和 Bot 消息。只接受绑定时扫码者的个人消息，不接受群消息或其他人的消息。文件消息通过腾讯 CDN 下载并按协议解密，单文件最多 50 MB、每条消息最多 10 个文件；下载在后台运行，新建、切换会话不等待下载。原文件统一出现在“资料库 → 上传文件”，支持的 PDF、DOCX、XLSX、PPTX、TXT、MD 自动进入后台索引，其他格式只保存。文件上传只发送收件确认，不调用聊天模型；本地会话历史也记录文件名和确认。随后直接发文字提问即可使用已有资料。不使用标签时，文字与一批文件可以按任意先后顺序发送，再发 `/attachment`，将当前会话最近的文字与连续文件作为一轮附件聊天提交。不会跨过上一条命令、XML 上传控制消息或已提交的附件批次；可用 `/attachment 新问题` 补充问题。收件确认仍会自动保存及索引文件。需要先收集再问答时，先发 `<attachment>`，再发文件与问题，最后发 `</attachment>`（也可 `/attachment [问题]`）。结束前只收集附件和问题，不调用聊天模型；结束时解析正文并发起一轮聊天。附件仍自动入库，原文件仍在资料库。本轮最多 10 个文件，收集状态按会话保存，重启后保留；`/attachment cancel` 取消本轮提交，不删除已入库文件。微信图片、语音和视频尚未接入，图片若以文件发送会保存原文件，但不做 OCR。

原始微信 `session_id` 和 `context_token` 用于渠道记录/回复路由，与内部 Agent 会话 ID 分开。回复回传对应入站消息的 context_token；稳定 client_id 由 Bot、用户和原消息 ID 生成。

## 后续运行与恢复

重复运行 `seudaily wechat` 会展示既有连接状态，不重复扫码。启动和停止时发送协议生命周期通知，通知失败不阻断服务。正常断网或接口失败时后台指数退避重试；成功后继续接收。凭证失效（协议错误码 -14）会暂停自动请求、保留凭证和待发送消息，需在 TUI 按 R 或网页点击“重新扫码”。微信报告已绑定而本地没有有效凭证时，按界面提示在微信解除旧绑定后重新接入。

退出客户端不会停止服务。手动停止用：

```sh
seudaily stop --data-dir /path/to/data --port 4111
```

再次启动 `serve` 或 `wechat` 会自动恢复已保存的绑定和消息游标。运行普通 CLI/Web 时，如果数据目录已有微信绑定，也会恢复微信并保持后端常驻；这是启用微信后的服务行为。取消一次扫码不会关闭常驻后端。

自动创建的常驻后端能在退出终端后继续运行，但操作系统重启后需要重新启动；需要开机启动和进程崩溃自动恢复时，使用 [systemd 服务说明](service.md)，仍以 `serve --with-web` 启动。先用同一数据目录完成微信接入，随后 `seudaily stop`，再交给 systemd 启动。不要在 systemd 管理时另开同端口的独立常驻进程。升级前停止服务，更新后重启，保留同一数据目录。1.1.7 起普通文字进入 Agent，不再使用固定 demo 回显；旧 demo 记录和绑定保留。更新后须重启旧后端，新版启动器会拒绝直接复用旧版后端。

## 本地存储及可靠性边界

数据位于 `--data-dir` 指定目录的 `.seudaily/agent.db`，使用现有 SQLite WAL、FULL 同步和串行事务机制：

- `wechat_account`：单个 Bot 的 token、Bot ID、扫码用户 ID、经过 HTTPS 官方域名验证的 API 地址、接收游标、是否需要重新登录。二维码和手机验证码只在内存中存在，不落盘。
- `wechat_messages`：原始微信 ID、peer、外部 session、内部 threadId/resourceId、文本、回复、带 context_token 的待发送 payload、微信源时间（接口提供时）、本机接收/准备回复/发送完成时间、附件下载引用及 received/command/queued/file/pending/sent 状态。入站先持久保存，再执行会话命令或交给 Agent；旧 demo 记录保留。
- `wechat_sessions`：按 Bot 和扫码用户隔离的固定会话编号及内部 threadId；`wechat_current`：该用户在微信当前选中的 threadId；`wechat_delete_confirmations`：待删除会话及 5 分钟确认有效期（重启保留）。
- Agent 的 `threads/messages/runs/summaries`：正式会话历史、执行状态和上下文摘要。微信资源为 `seudaily-wechat-local`，共享现有 Web/TUI 历史展示；会话命令不会混入模型聊天上下文。
- 入站消息去重插入与游标提交处于同一事务；游标只有成功响应中的非空新值才会更新。重启继续处理已入站消息和待发送回复，再继续长轮询。会话新建/选择与消息路由在同一事务中提交；重复入站不会重复执行 `/new`。模型轮次使用稳定运行 ID；已完成回答可恢复发送，服务中断的工具执行不会自动重放。

文件和目录按私人数据权限保存。Bot token、验证码、context_token 不在状态 API 或界面中返回；不要公开数据库。日志不记录腾讯响应正文或凭证。API 重定向仅接受 `https://*.weixin.qq.com` 的根地址，HTTP 自动重定向被拒绝，避免凭证被转发到其他站点。

网络可能在腾讯已接受回复、客户端尚未记录成功时断开。因此发送采用持久队列和稳定 client_id 重试；不能承诺腾讯服务端一定去重或端到端严格一次投递。如果长期没有网络，旧 context_token 也可能失效，界面会保留等待回复状态和错误提示。

目前不实现图片/语音/视频消息接收、群聊或定时数据库备份。支持的文件已接入资料库与 RAG。附件已有存储位置参见 [service.md](service.md)。

## 自动验证与人工测试

自动测试使用模拟 HTTP transport，覆盖腾讯请求头与字段、二维码跳转和手机验证码、凭证过期、游标/消息原子提交、重复消息去重、发送失败重试及重启恢复；不连接真实微信账号。真实账号请重点测试首次扫码、`/help`、新建/切换/上下文/历史、模型文字聊天、退出客户端仍收发、重启服务自动恢复，以及微信端解除绑定后的重新登录。

### 权限与文本审批

发送 `/permission` 查看当前模式及可选模式；发送 `/permission normal`、`/permission full` 或 `/permission extra` 直接切换。normal 对需要审批的操作逐项确认，full 让业务和浏览器操作免审批，extra 另启用工作区文件和终端能力。设置与 Web/TUI 共享，写入数据目录 `.env`，重启后保留。切换不会自动批准已经暂停的任务。终端也支持 `/permission`，原 `/mode` 保留。

待审批消息会显示真实操作内容及四位短码，例如“确认 A31D”或“取消 A31D”。兼容原八位编号，输入开头或末尾至少四位即可，字母不区分大小写；若短码对应多个操作，会提示使用完整八位编号。`/approve` 或 `/deny` 不带编号时展示当前待审批操作；确认或取消必须携带编号。编号绑定当前会话和待审批调用，切换会话、重复确认或使用过期编号均不会执行其他任务。控制命令不调用模型；审批恢复原来的模型任务，不新建会话。断线后可继续处理待审批任务，已明确批准的调用不受发现票据十分钟有效期限制，也不会重放已执行的写操作。

学期总周数默认 16，已有明确保存的自定义周数继续保留。只设置起始日期时不改学期名称或总周数；模型不得自行填充这些字段。升级前已经提出的审批保留原参数，需取消不正确的旧请求后重新发起。

## 延迟排查

`/new` 只操作本地数据库，不调用聊天模型。后端日志记录该命令的 deliveryMs（微信消息创建到本机收到）、localMs（收到到回复准备完）、sendMs（回复准备完到发送接口确认）三个阶段。接口缺少源时间时 deliveryMs 为 null，不能据此判断收件耗时。发送接口确认不代表手机已经展示消息。历史消息没有新增时间记录，不倒填推测值。
