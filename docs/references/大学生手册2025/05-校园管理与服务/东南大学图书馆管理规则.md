# 东南大学图书馆管理规则

来源：《东南大学大学生手册》2025 年校订本；东南大学校长办公室编，二〇二五年八月。

第一条凭本人有效校园卡刷卡（人脸识别）进出馆，因未携带校园卡或其他原因不能正常入馆者可凭本人有效身份证件登记入馆，严禁使用他人证件入馆。

第二条遵循图书馆的公共场所规范，主要包括：

- （一）讲究公共礼仪，仪表整洁大方；

- （二）根据馆内不同区域功能要求，保持安静或小声交谈；

- （三）讲究公共卫生，保持环境整洁，移动阅览座位后请及时复位；

- （四）禁止在阅览区及书库内用餐、吃零食、喝由无盖器皿盛装的有色饮料。

第三条遵守借阅规则，主要包括：

- （一）凭本人校园卡办理图书借阅手续；

- （二）校园卡不得转借他人使用，因遗失或转借而产生的问题由本人负责；

- （三）续借、预约和委托借还图书，遵守图书馆相关规则（详见《图书借阅规则》《图书馆图书委托借还服务工作规程》）；

- （四）请勿将未办理借阅手续的图书带出馆；

- （五）学生离校前应归还借阅的图书，并处理完相关手续。

第四条文明使用馆藏文献资源和设施，主要包括：

- （一）不在书刊、家具、设备上随意写划，不撕、挖、折书页；

- （二）自觉维护图书馆运行秩序，文明使用阅览座位，严禁占座，离馆时带清个人物品；

- （三）合理使用预约空间，遵守各类空间使用规范；

- （四）按操作规程使用检索机、影音设备、录播设备、自助借还设备、公用计算机等各类自助服务设施，禁止随意搬动、调整图书馆服务设施。

第五条提高图书馆的公共场所安全防范意识，主要包括：

- （一）严禁携带易燃、易爆品人馆；

- （二）严禁在馆内任何地方吸烟或使用明火；

- （三）严禁随意触碰消防按钮、监控探头等设施；

- （四）贵重物品随身携带，谨防遗失；

- （五）离馆时如遇门禁系统报警，请自觉配合工作人员和保安检查。

第六条合理使用图书馆购买的电子资源（详见《关于电子资源版权的公告》）。

第七条自觉遵守图书馆各项规章制度，接受工作人员的依章管理。如有违反图书馆规章制度的行为，按《图书馆违章处理工作规则》处理。

第八条本规则由学校授权图书馆负责解释。
