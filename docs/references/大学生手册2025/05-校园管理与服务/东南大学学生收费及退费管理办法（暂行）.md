# 东南大学学生收费及退费管理办法（暂行）

来源：《东南大学大学生手册》2025 年校订本；东南大学校长办公室编，二〇二五年八月。

## 第一章总则

第一条为了加强和规范我校学生收费管理，保障学校和学生的合法权益，根据国家的有关规定，并结合我校的实际情况，特制定本办法。

第二条本办法适用于按国家规定被我校录取的接受普通高等学历教育的全日制学生。

## 第二章缴费管理

第三条高等教育属于非义务教育阶段，学校依据国家有关法律和规定，向在校学生收取有关费用。

第四条学生在校期间，应按规定时间缴纳学费及有关费用，确因家庭经济困难而暂时不能缴纳费用的本科生可以通过学生处、研究生通过研究生院办理缓缴手续。新生可通过学校开设的“绿色通道”办理入学手续、缓缴学费等，报到后一周内，需本人提出系统申请，所在院（系）审核，学校审批确认缓缴手续，经学校批准后予以注册。超过缓缴期限的学生，若家庭经济确有困难，仍然不能缴纳费用的，经院（系）确认，学生处或研究生院审批，学生可以通过制定在学校规定时间内的还款计划，在规定时间内可参加学校正常的教学活动。未按学校规定缴纳费用或者其他不符合注册条件的不予注册。若影响其选课及其他教学活动的，按《东南大学全日制本科学生学籍管理规定》的有关规定处理。

第五条全日制本科生实行学分制收费管理，其收费方式采用预收结算制。根据我校2019年大类招生、大类培养工作部署，按大类招录的新生入学第一年实行预收学费，一年后分流选择专业时，按照分流后的专业收费标准收取学费，并对第一年预收学费结算。结算原则为：分流后的专业收费标准高于原预收学费的，不再收取少交部分；分流后的专业收费标准低于原预收学费的，退还多交部分（调整第二年学费）。本次学费标准调整实行“新生新办法、老生老办法”，从2019年秋季入学新生开始执行新规定，在校老生仍按原规定执行。

第六条根据《关于调整2019级、2020级本科生学费收费方式的通知》，我校对2019级、2020级及以后本科生学费收费进行了调整。自2019级开始执行，其他年级在校生按原收费方式执行。

- （一）自2019级开始，我校文、理、工、医学、艺术各专业本科生正常修读课程学费按学年收取。学生毕业离校前根据在校期间所修读的总学分数和所在专业培养方案要求毕业需达到最低学分数差值计收学费，方法如下：

- 1.在校期间所修读的正常选课课程总学分数≤专业培养方案要求毕业最低学分数+5，免收加修学费；

- 2.在校期间所修读的正常选课课程总学分数>专业培养方案要求毕业最低学分数+5，超出部分按规定的学分收费标准计收学费；

- （二）重修、辅修的收费按照实际报名、选课情况每学年根据所修课程规定的学分收费标准结算学费。

第七条学籍异动（除延长学习年限的）学生按照学籍异动后所在年级和专业标准执行。学籍异动要离校的学生按当学年实际修读所有课程学分结算学费，结清后方可离校。

- （一）正常毕业的学生网上即可办理相关离校手续。毕业年级学生，在学校毕业班学分结算工作结束后，学生因退学、休学、转学、因私出国留学、转出、提前结束学业的，按毕业班结算学分结清应缴费用。除此之外，学生因退学、休学、转学、因私出国留学、转出、提前结束学业等原因离开学校，本人应持教务处开出的“离校流转单”及相关已修学分证明到财务处结清应缴费用后，方能办理离校手续。

- （二）转系转专业、转入下一年级、转入上一年级、延长学习年限（在校学习）等发生学籍变动的学生，无需本人持有关管理部门开出的“流转单”到财务处办理相关手续，财务处会根据教务处每月提供的学籍异动名单统一进行处理。

- （三）学生在校就读期间，因学籍异动（含转系转专业、复学、转入上一年级、转入下一年级等）发生年级及专业变动，按照学籍异动后所在年级和专业标准执行。

- （四）延长学习年限的学生按实际选课情况每学年根据学分数结算学费。

第八条二年制攻读二学位的新生，按照所属专业学年收费。

第九条实行学分制收费后，学生提前一年毕业的，少收一年的专业学费，提前一学期毕业的，少收半年专业学费。

第十条实行学分制收费后，学校给考试不及格未能取得该课程学分的学生一次免费补考机会。补考后仍不及格，需重新学习该门课程，应在修读学期按该课程的学分收费标准交纳学分学费。

第十一条实行学分制收费后，经本人申请，所在专业学院和教务处审批同意获得课程免修者，带有实验、实践环节的课程可按该课程规定的学分学费标准缴纳1/3的学分学费，其它课程不收学分学费。

第十二条因高等院校国际交流，学生出国学习期间按在校生标准缴纳相关学费。

第十三条在校期间，住宿学生应根据实际住宿条件和物价部门核定的收费标准缴纳住宿费。

- （一）在学年中正常住宿的学生，按本年实际住宿标准全额缴纳住宿费。

- （二）中途申请住宿的学生，按实际住宿时间按月缴纳住宿费。

- （三）提前毕业的学生，按实际住宿时间按月缴纳住宿费。

- （四）延期离校的学生，根据实际延长时间续缴住宿费。

- 1.延期未办理离校手续的学生按实际居住的宿舍标准缴费，如宿舍调整，按调整后宿舍的住宿费标准缴费，如遇学校住宿费标准调整，延长一学期以内的学生按原住宿费标准缴费，延长一学期以上的学生则按调整后的住宿费标准缴费。

- 2.延期离校住宿学生续缴住宿费，计费时间自规定学制结束后的次月起，根据学生的实际住宿时间，按月计缴住宿费。情况特殊的，经学生处或研究生院批准，可再延长一个月（免缴住宿费）。所有延期离校学生必须服从学校宿舍调整的安排。

第十四条学生在校期间，按规定缴纳的其他应缴费事项。

- （一）学生在所修专业规定毕业最低学分之外加修、跨专业选修、辅修的，按所修课程规定的学分计收学分学费。

- （二）补办学生证、校园卡、火车票学生优惠卡等，按不超过证、卡工本费的2倍收取补办费用。

- （三）符合国家和地方规定的其他收费事项。

第十五条学生缴费

- （一）学生缴费方式学生（含延长学制的学生）通过东南大学缴费平台缴纳费用（http：//caiwuchu.seu.edu.cn）。留学生新生缴费方式另行通知。

- （二）延期离校学生，经归口管理部门核准后，直接向学校财务处或财务处指定地点续缴延期住宿费。

## 第三章退费管理

第十六条学生因学籍变动发生应退费用，其应退费用的计算时间从学生正式办理学籍变动手续之日算起（以“离校流转单”注明的日期为准）

第十七条实行学分制收费后，因各种原因退学、转学、出国留学等终止学业的，在学年第一学期开学一个月内批准的，全额退还其专业学费；原则上超过一个月的退还50%的专业学费，第二学期内批准的不退还专业学费。

第十八条学生因病等原因休学，可以比照退学退费的规定退还有关费用。学生休学期间，不交纳专业学费和学分学费。休学期满复读，按随读年级和专业标准收取相关学费。

第十九条实行学分制收费后，学生选定修读课程后，可自该课程开课后试修2周。学生因各种原因在开学后第三周内退选课程的，免收退选课程的学分学费。

第二十条学生在校期间，因个人特殊原因需退宿或调整宿舍的，应及时办理审批和调整手续，并按规定进行住宿费的退费和调整。

- （一）学生退宿或调整宿舍，须从东大信息化或网上办事大厅“学生公寓系统”内进行线上申请，经审批后方可办理宿舍变动手续。每月由归口管理部门统一将表格送交财务处办理住宿费退费或调整事宜。

- （二）学生在学年内退宿的，按实际住宿时间按月计退剩余的住宿费。住宿费退费或调整时间从宿舍管理员签字确认之日起开始起算。如因特殊情况，填表日期与实际退宿（调整）日期不相符，学生应写明原因，经宿舍管理员审核确认并在审批表上注明实际退宿（调整）日期后，送交相关部门审批。

- （三）硕博连读、提前攻博学生，入住博士宿舍，不需要特别办理退宿，财务处依据归口管理部门提供的学生实际住宿情况完成住宿费收取或退费；如不入住博士宿舍，应及时办理相关退宿手续。

## 第四章附则

第二十一条本办法执行过程中，如遇国家和地方出台新的收费规定，则按新的规定执行。

第二十二条研究生学费收费管理参照江苏省相关文件执行，留学生收费管理办法另行制定。

第二十三条本办法学校授权财务处负责解释。东南大学本科生学生评教管理办法

第一条指导思想学生对教师开展的课堂教学进行评价（以下简称“学生评教”）是课程课堂教学质量评价的重要途径，学生评教结果是评价教师教学质量的重要依据之一。学校坚持“以评促教，以评促改，教学相长”的理念，鼓励学生充分发挥学习的主体性，积极参与教学管理，推动提高课堂教学质量和教学效果。

第二条组织管理

- 1.学校每学期开展学生评教工作，分为过程性评教和期末评教两种。过程性评教不定期开展，主要用于实时了解课堂教学基本情况，期末评教于每学期末开展，主要用于了解学生对于教师及其课程教学效果的综合评价。

- 2.学生评教范围涵盖所有本科课程课堂教学班，评价对象为教学班课程任课教师，评价主体为全日制在校本科生。

- 3.学生评教依托“网上评教（本科）”平台开展网络评教，为全员参与。学生应本着实事求是的原则，认真阅读评教指标内容，及时客观公正地填写评教问卷，不允许代替他人或找他人代为评教。

- 4.对于期末评教，学生需在评教开放期间内对自己所选课程的教师教学情况进行评价，完成后方能实时在线查看课程成绩。

- 5.鼓励师生对学生评教工作进行监督，对于违反相关规定的行为，将按照学校有关规定，予以处理。

第三条信息反馈

- 1.教师教学发展中心负责学生评教工作的组织和管理，评教结束后对有效数据进行汇总、统计和分析，形成报告并及时反馈给学院和相关部门。

- 2.教师可在网上评教系统查询本人的评教成绩和匿名学生主观评语。学生可在网上评教系统查询自己的课程评教情况及相关分析数据。

第四条本办法学校授权教师教学发展中心负责解释。
